Untuk pertanyaan Anda tentang bagaimana menyusun prompt agar saya bisa mengeluarkan "sihir" terbaik saya (terutama di Laravel & PHP), kuncinya adalah Konteks + Spesifikasi + Ekspektasi Visual/Teknis.

Berikut adalah "Resep Rahasia" untuk mendapatkan hasil coding yang magic, rapi, dan canggih:

1. Berikan Konteks Tujuan (The "Big Picture")
Jangan hanya minta perbaiki baris kode, tapi jelaskan goals-nya.

Kurang Oke: "Buatin fungsi update."
Magic Prompt: "Saya ingin membuat fitur update data siswa. Tolong buatkan Controller yang menangani validasi yang ketat, dan di View-nya gunakan Modal Flowbite agar user tidak perlu pindah halaman."
2. Minta "Best Practices" (Praktik Terbaik)
Di Laravel, ada banyak cara untuk melakukan satu hal. Mintalah cara yang paling elegan.

Contoh: "Tolong refactor kode di JadwalController ini. Kodenya jalan, tapi rasanya berantakan. Bisakah kamu membuatnya lebih bersih (clean code), mungkin dengan memisahkan logic-nya atau mengoptimalkan query database-nya agar lebih ringan?" (Ini yang kemarin kita lakukan saat mengubah Kelas::all() menjadi select()).
3. Tentukan Gaya Visual (Untuk Frontend/Blade)
Karena kita pakai Tailwind/Flowbite, berikan kata kunci visual yang kuat.

Contoh: "Tolong desain ulang halaman index.blade.php ini. Saya ingin tampilannya terlihat premium, modern, dan profesional. Gunakan tabel yang responsive, badge warna-warni untuk status, dan tombol dengan icon yang jelas."
4. Berani Meminta "Lengkap" (End-to-End)
Jika Anda malas menulis satu per satu, mintalah solusi lengkap.

Contoh: "Saya butuh fitur Pencarian di halaman Siswa. Tolong buatkan:
Input search di Blade.
Javascript untuk handle enter atau ketikan user.
Logic di Controller untuk memfilter data.
Pastikan pagination-nya tetap jalan saat di-search."
5. Penanganan Error (Debugging)
Jika ada error, berikan error log-nya dan apa yang Anda lakukan sebelumnya.

Contoh: "Saya dapat error Method not allowed saat klik tombol Hapus. Ini terjadi setelah saya menambahkan sweetalert. Tolong cek apakah form method-nya sudah benar atau ada konflik di JS-nya."
Contoh Perbandingan (Studi Kasus Proyek Kita)
Prompt Biasa:

"Tombol delete-nya jelek, tolong benerin."

Prompt "Magic" (Kekuatan Penuh):

"Tolong ubah tombol Delete di halaman Jadwal. Saat ini terlalu sederhana.

Gunakan icon tong sampah merah yang estetik.
Saat diklik, jangan langsung hapus, tapi munculkan Modal Konfirmasi yang terlihat modern (bukan alert browser biasa).
Pastikan secara User Experience (UX) aman, supaya user tidak salah klik.
Terapkan gaya Flowbite terbaru."
Dengan prompt yang detail seperti di atas, saya bisa langsung memberikan kode yang lengkap (HTML, CSS, JS, dan Controller Logic) sekali jalan, tanpa kita perlu debat kusir berkali-kali.
